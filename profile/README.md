# 👁️ Computer Vision Laboratory

Welcome to the official repository of the **Computer Vision Laboratory**.

This repository contains all the practical material used during the course.  
The laboratory sessions are designed to guide students step-by-step through the implementation of fundamental Computer Vision techniques using **Python**.

## ⚡ Get Started

Before the first laboratory session, you need to create your **Lightning AI** account, since all coding activities during the course will take place there.

Go to [Lightning AI](https://lightning.ai) and click on Sign Up.
‼️ Register using your university email address. By signing up with your institutional email, you can access the student free plan, which is completely sufficient for this course. No payment is required.

## 🧪 Laboratory Structure

All laboratory sessions run on **Lightning AI**, our shared cloud workspace for the course. This means you don’t have to install anything on your computer or worry about configuration problems. No setup headaches, no version conflicts — just open the environment and start coding.

Each lesson includes:

### 📌 1. Live Coding

- Python code written and explained live  
- Step-by-step development of algorithms  
- Interactive experimentation  

### 📓 2. Summary Notebook

After the lecture, you will find a structured **Jupyter notebook** that:

- Summarizes the theoretical concepts  
- Contains the cleaned and structured version of the code  
- Includes explanations and visual results  

### 📝 3. Optional Assignment (Exam Preparation)

In addition, each lesson includes an optional assignment notebook to be completed at home. The assignment is meant to deepen your understanding and strengthen your problem-solving skills in preparation for the exam.

The assignment is designed to:

- Reinforce understanding  
- Prepare you for the exam  
- Encourage independent reasoning  

For each task in the assignment:

- 💡 You will find hints to guide your solution if you need help
- 👀 If you are unsure how to approach the implementation, you will also find a structured solution outline in bullet points to help you organize your reasoning

These elements are provided in spoiler format, so you can decide whether to reveal them. **We strongly suggest to first attempt each exercise independently.** If you feel stuck, you may choose to open the spoilers progressively: first the hints, and only later the solution outline.

⚠️ The full final solution will not be provided immediately. At the beginning of the following lesson, we will dedicate time to reviewing the assignment together. 

‼️ Assignment solutionts, slides, quiz and video lecture will be available on Moodle
